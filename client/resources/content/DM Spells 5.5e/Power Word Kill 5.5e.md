# Power Word Kill

*Level 9 enchantment*

| | |
| --- | --- |
| **Casting Time** | action |
| **Range** | 60 feet |
| **Components** | V |
| **Duration** | instantaneous |

You compel one creature you can see within range to die. If the target has 100 Hit Points or fewer, it dies. Otherwise, it takes 12d12 Psychic damage.
